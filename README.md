## 公開について

このリポジトリは文書の保管先です。作成時点ではGitHub Pagesの有効化や、既存の作品一覧へのリンク追加は行っていません。

GitHub Pagesで公開する場合は、Settings → Pagesでmainブランチのルートを公開元に指定してください。公開完了後のページURLを、誤警告の再審査フォームの「プライバシー ステートメント」欄に使用できます。
